# Модуль: Маркировка (план, не начат)

## Идея

Ежедневная маркировка продуктов на кухне: сотрудник выбирает полуфабрикат из существующих техкарт (автодополнение по названию), дата/время/имя сотрудника подставляются автоматически. Печать — на этикеточный принтер на кухне, физически подключённый к компьютеру, где стоит Sync Agent.

## Статус: идея признана реализуемой, ничего не написано

Ждём физического подключения принтера — тестировать вслепую без железа под рукой смысла нет (тот же принцип, что и с накладными — сразу на реальных данных).

## Принтер

**Brother QL-810W** — куплен, ещё не подключён.

- Ставится в Windows как обычный принтер (фирменный драйвер Brother) — не нужно разбираться с ZPL/TSPL.
- USB-подключение к компьютеру с Sync Agent.
- Есть SDK (b-PAC) для программной печати по шаблону, но для задачи должно хватить более простого пути.

## Планируемая архитектура

```
StockFlow (кнопка "Напечатать")
  → новая таблица в Supabase (запись маркировки)
  → Sync Agent (новый watcher, опрос по расписанию)
  → генерация картинки нужного размера
  → тихая печать на Windows-принтер (без диалоговых окон)
  → физический стикер
```

## Решённые вопросы

- Печать — **по отдельной кнопке "Напечатать"**, не автоматически при создании записи.
- Лента — рекомендована **непрерывная** (не die-cut фиксированного размера) — гибче под разную длину названий блюд.
