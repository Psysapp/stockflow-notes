# Официальный справочник процедур StoreHouse API — найден!

**Главная находка 04.08.2026:** есть полный официальный список ВСЕХ процедур сервера с их назначением — `https://docs.rkeeper.ru/sh5/protsedury-servera-19612514.html`. Это решает всю проблему "угадывания названий", с которой мы боролись весь день 02–03.08.

## Остатки — решено

**`GRemns`** — "Ведомость остатков" (`https://docs.rkeeper.ru/sh5/gremns-vedomost-ostatkov-27852549.html`). Полная официальная спецификация параметров:

**Вход (минимум):** только дата отчёта (`head=108, path="1"`, тип дата). Остальное — необязательные фильтры (юр.лица, предприятия, подразделения, товарные группы).

**Выход** (`Array 151`, "Отчёт по остаткам"):
- `31` — **Количество остатка** (то, что нам нужно!)
- `40` — сумма себестоимости без налогов (альтернативный источник цены/себестоимости)
- `41`/`42` — НДС/НСП
- `210\1` — RID товара
- `210\3` — наименование товара
- `210\206\3` — единица измерения

Похоже, можно получить остатки **по всей организации одним запросом** (как `Cmps` для комплектов) — не нужно запрашивать по одному товару. Проверяется скриптом `probe-gremns.js`.

## Другие полезные находки из справочника (на будущее)

- **`Corrs`** — "Корреспонденты: список" — возможно, гораздо более простой способ получить список поставщиков, чем `UContractors` (с которым мы мучились 02–03.08 из-за незаполненного поля "тип" у контрагентов, см. [[01 Архитектура/StoreHouse API]]). Стоит проверить вместо/вместе с `UContractors`.
- **`CntrSpecs`** — список КПП контрагента.
- **`GoodsPCost`** — расчёт себестоимости товара по FIFO (ещё один источник цены, точнее чем Price0/Price1).
- **`GoodsItem`** — свойства ОДНОГО товара (может пригодиться для "живых" точечных запросов вместо полного отчёта).
- **`RptSale`/`RptDSale`** — акт реализации / по дням — на будущее, если понадобится ИИ-функция "что продавалось".
- **`GDoc0`** — приходная накладная (может пригодиться, если решим когда-то читать накладные напрямую из StoreHouse, а не только писать).

## Структура справочника (для навигации в будущем)

Разделы: Словари (валюты, юр.лица/предприятия/подразделения, корреспонденты, единицы измерения, категории товаров, товарные группы, товары, налоги, страны/регионы) → Документы (накладные всех типов, заявки, отчёты, ЕГАИС) → Связь с другими системами (Repl*-процедуры для синхронизации между базами).

Каждая процедура в справочнике — отдельная страница с полным описанием In/Out parameters, как в примере с GRemns выше. Если понадобится найти ещё что-то — сначала смотреть сюда, а не гадать через SdbMan/скриншоты.
