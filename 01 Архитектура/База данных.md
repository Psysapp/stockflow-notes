# База данных (Supabase)

Проект: `cdcyspbfoxknhnyoxzkm` (eu-central-1). 24 таблицы в схеме `public`, мультиарендная модель — всё привязано к `organization_id`.

## Ядро: организации и люди

```
organizations
 ├─ organization_members ── user_id → auth.users
 │    └─ member_locations ── location_id → storage_locations
 ├─ invitations (по email)
 └─ storage_locations — точки учёта
```

## Каталог из StoreHouse

- **`sh_products`** — товары/полуфабрикаты, синхронизируется из StoreHouse (GGroupsTree/Goods). Поле `embedding` — вектор для семантического поиска (используется `match-product`).
- **`sh_suppliers`** — поставщики. **Почти пустая** (была 1 запись на момент анализа) — нормальной синхронизации поставщиков ещё нет, см. [[01 Архитектура/StoreHouse API|StoreHouse API]].
- **`ai_match_cache`** — кэш ИИ-сопоставлений (raw_text → matched_id).

## Техкарты

```
tech_cards ── tech_card_ingredients
```

⚠️ **Известная проблема:** `tech_card_ingredients.product_id` ссылается на таблицу **`products`**, которая пустая (0 строк) — это мёртвый FK, оставшийся от старой архитектуры до перехода на `sh_products`. Реально используется только текстовое поле `product_name`. Не исправлено.

## Мониторинг (добавлено 02.08.2026)

- **`sync_agent_logs`** — логи Sync Agent льются сюда параллельно с локальным файлом (кроме огромных сырых дампов CmpDetails).

## Storage (файлы)

Два бакета:
- **`avatars`** (публичный) — аватарки, `{user_id}/avatar.jpg`
- **`storehouse-exports`** (приватный) — обмен XML со StoreHouse, путь `{organization_id}/{filename}.xml` (для документов с subfolder — `{organization_id}/{subfolder}/{filename}.xml`)

## Безопасность (RLS)

Все таблицы используют одну функцию `is_org_member(org_id)` — любой участник организации технически может прочитать/изменить что угодно в своей организации через прямой API-запрос, независимо от роли (owner/manager/employee). Разделение по ролям — только на уровне интерфейса. Приемлемо для внутреннего инструмента сейчас, но учитывать при появлении чувствительных данных (зарплаты и т.п.).
